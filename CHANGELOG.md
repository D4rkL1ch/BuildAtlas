# Build Atlas

First release.

- Talent planner for every class with the game's own tree, plan slots for scratch and both specs, and clear reasons when a rank can't be taken.
- Talent explanations: which spells each talent changes, what it scales with, proc chains, resource loops and how it differs from Classic. Spell tooltips show which of your talents change them.
- Synergy map and build comparison.
- Import and export: Build Atlas strings, the game's loadout string, Wowhead links and SimC profiles; share builds with your party, guild or a friend.
- Apply a plan to your character (adds points only, never in combat).
- Fight report with an estimate of each talent's share, and a training-dummy benchmark.
- Stat weights, Pawn support, bag upgrade check, consumables and enchant checklist.
- Presets and a leveling path with an optional level-up reminder.
